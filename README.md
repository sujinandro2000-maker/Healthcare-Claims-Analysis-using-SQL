# Healthcare Claims Analysis using SQL

## 📌 Project Overview

This project analyzes a synthetic Healthcare Revenue Cycle Management (RCM) dataset using SQL.
The goal is to understand claim status, aging trends, insurance performance, and outstanding balances through SQL queries.

Healthcare organizations use similar analysis to track revenue, identify denied claims, and improve billing efficiency.

---

## 📊 Dataset Information

The dataset contains healthcare claim information including:

* Client
* State
* Visit ID
* Patient Name
* Date of Service (DOS)
* Aging Days
* Aging Bucket
* Insurance Name
* Claim Status
* Billed Amount
* Balance Amount
* Assigned To
* Worked By
* Follow Up Date

---

## 🛠 Tools Used

* MySQL
* SQL
* GitHub

---

## 🔍 Analysis Performed

The following analysis was performed using SQL:

1. Total number of claims
2. Claim status distribution (Paid, Pending, Denied)
3. Total billed revenue
4. Outstanding balance analysis
5. Denied claims by insurance company
6. Aging bucket analysis
7. High value claims
8. Employee claim work analysis

---

## 📈 Key Insights

* Identified the distribution of claims across different statuses.
* Calculated total billed revenue and outstanding balances.
* Analyzed insurance companies with higher claim denial rates.
* Evaluated aging of claims to identify delayed payments.
